This is the backend of the budgeting app

# Guidelines
- The backend must always be stateless. The backend should not store state related to the user
    - All information related to the user must always be stored in a database
- Use Session Cookies for storing user sessions. Avoid using JWTs
- Always store credentials (Database URLs, login details, etc.) in a .env file
- Prefer integration tests over unit tests. 

# Structure
## Codebase
`cmd/` - Initializes the API. 
`internal/`  
    - `database/` - Database related 
`middleware/` - Middleware
`services/` - Where most of the business logic lies in
`tests/` - Integration tests. Prefer using Go's requests to make requests
`main.go` - Starting point of the backend

## Database
This project uses SQLC and Goose in order to manage database schemas and queries

### Creating Migrations
To make a migration

1. Create a migration using `goose`. Always use `sql` as the language. 
```
goose create new_migration sql
```
2. Add necessary schemas to the migration file. Always add a way to roll back migration changes
```sql
-- +goose Up
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username text NOT NULL
);
-- +goose Down
DROP TABLE users;
```
3. Apply the migration using `goose up`

### Creating Queries
To make a function that queries a database
1. Make a file in `/internal/database/queries`. Always respect the boundaries of each item (i.e. user related queries should only be found in `users.sql`)
2. Create the query as so
```sql
-- name: ListUsers :many
SELECT * FROM users ORDER BY username;
```
3. Generate the Go code using `sqlc generate`

## Services
Each service in the backend is organized as per feature. 
- `service.go` - The business logic of the project
- `handler.go` - The handlers that will be given to the server

Note that this is missing a file containing the types. The types are generated by `sqlc` 

Example Structure:
```go
// users/handler.go
type UserHandler struct {
    users *UserService
    auth  *AuthService // Obtained using dependency injection
}

// Handles the "GET /user/profile/" endpoint
func (h *UserHandler) profile(w http.ResponseWriter, r *http.Response) {
    h.auth.AuthUser()  // from auth/service.go
    h.svc.GetUserProfile()
    h.svc.GetUserPosts()
}

// users/service.go
type UserService struct {}

func (s *UserService) GetUserProfile() {}
func (s *UserService) GetUserPosts() {}
```
