# Project Overview
This app helps users manage their savings. 

## Features
1. User can view all their savings per bank account
2. User can also see their account balance in different currencies (if they own foreign currency)
3. User can make a wishlist / savings goal for items they want in the future

## Limitations
- No live updates for account balances. User has to manually input their data here
